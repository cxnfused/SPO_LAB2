Анализатор метрик Джилба (PHP)
Учебное веб-приложение для статического анализа PHP-кода и расчёта метрик Джилба:
- CL — количество учитываемых управляющих конструкций;
- n — количество операторов по правилам анализатора;
- cl = CL / n — относительная сложность;
- CLI — максимальная вложенность условий и циклов.
Запуск
1. Установите XAMPP и запустите Apache.
2. Поместите файлы index.php и sample.php в папку C:\xampp\htdocs\lab2a\.
3. Откройте http://localhost/lab2a/index.php.
4. Измените PHP-код в поле ввода и запустите анализ.
index.php содержит интерфейс и анализатор, sample.php — пример программы. Анализируемый код не выполняется. Для неподдерживаемых конструкций возможны ограничения расчёта.
