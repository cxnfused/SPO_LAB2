# Floreal Mobile App Generator — Figma Plugin

Плагин создаёт в Figma презентационный постер мобильного приложения цветочного магазина в стиле примера: 9 экранов, фон, декоративные цветы, карточки, кнопки, каталог, корзина, оформление заказа и профиль.

## Как установить

1. Распакуй ZIP.
2. Открой Figma.
3. Открой любой Design-файл.
4. Меню Figma → Plugins → Development → Import plugin from manifest...
5. Выбери файл `manifest.json`.
6. Потом запусти: Plugins → Development → Floreal Mobile App Generator.

## Что получится

Плагин создаст:
- большой постер `Floreal — mobile app presentation`;
- 9 экранов приложения;
- подписи 01–09;
- декоративный фон;
- цветочные SVG-заглушки;
- карточки товаров, кнопки, поля ввода, корзину, профиль.

## Важно

Это не вставка готовой картинки, а редактируемый макет. Фото букетов лучше заменить на свои реальные изображения:
- перетащи фото в Figma;
- положи поверх заглушки;
- используй Crop/Fill.

Для экспорта постера:
- выдели большой frame;
- справа в Export выбери PNG/JPG;
- нажми Export.
